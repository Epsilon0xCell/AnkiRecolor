AnKing ReColor

AnkiRecolor

Repaint Anki in one stroke

ReColor your Anki desktop to whatever aesthetic you like. The README suggests pairing it with the Custom Background and Gear Icon add-on for the full look.

Get it on AnkiWeb The repo

How to use it

  1. Download the add-on from AnkiWeb. It has been tested for Anki 2.1.41 and up to 2.1.50. It may work on older versions, but those are untested and unsupported for now.
  2. After installing, an AnKing menu appears at the top. Click the ReColor submenu to open the ReColor dialog.
  3. The colors listed are everything Anki customizes. One honest limit, stated in the README: some things are linked together, so changing one changes the other, and there is no way around that from the add-on side.
  4. Click Save, and the colors update.
  5. Click Advanced if you want to input HTML colors or see the underlying code.

I keep this fork in the fleet for a simple reason: study software is on screen for hours every day, and the person doing the studying should get to pick the colors. Share your result with the tag the README gives, #ReColorAnKing, and tag @AnKingMed so the upstream team can re-share it.

Under the brush

Development notes from the README: the icons resource file is rebuilt from src/addon/AnKing/icons.qrc with pyrcc5, then edited to add a -> None type hint. The project uses mypy for Python type checking and standardjs for JavaScript formatting:

python -m mypy .   npx standard --fix
